# تصنيف البيانات

| الفئة | أمثلة | القاعدة |
|---|---|---|
| عامة | وثائق منشورة مرخصة | تخضع للترخيص والإصدار والمصدر |
| مؤسسية | خطط، قوالب، موارد أستاذ | RLS حسب المنظمة، لا مشاركة عامة افتراضياً |
| حساسة | نتائج أو ملاحظات قد تحدد متعلماً | ممنوعة في MVP إلا بتصميم وموافقة لاحقة |
| سرية | service keys، API keys، backups | لا تدخل Git أو logs أو prompts |

لا ترسل بيانات شخصية أو نتائج فردية إلى LLM. يجب تنقيح logs والمدخلات قبل أي خدمة خارجية.
