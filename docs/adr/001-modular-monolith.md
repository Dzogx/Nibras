# ADR-001: Modular Monolith أولاً
- **الحالة:** مقبول.
- **السياق:** بيانات الوثيقة والخطة والمورد والتقويم مترابطة، والفريق صغير في البداية.
- **القرار:** Next.js/TypeScript مع modules حدودها واضحة وworkers منفصلون للمهام الطويلة؛ لا Microservices مبكرة.
- **العواقب:** سرعة أعلى وسطح تشغيل أقل؛ يجب منع imports العابرة للحدود وتوثيق APIs الداخلية.
